# Security policy

Astha Chopa is fully offline: it makes no network requests and stores games and settings only on the device.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's [private vulnerability reporting](https://github.com/rachittyagi/astha-chopa/security/advisories/new) instead.

Include the affected version or commit, steps to reproduce and the impact you expect. You should get a reply within 7 days.

## Supported versions

Only the latest commit on `main` is supported.
